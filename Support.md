# Support

Thanks for using VS Code Theme Randomizer.

## Get Help

If you run into a problem, the best way to get help is to open a GitHub Issue.

Repository Issues page:
https://github.com/skyhoshi/vscode-theme-randomizer/issues

## How to Submit an Issue with a Report Template

1. Open the Issues page.
2. Click New issue.
3. Choose Bug report (or the closest template).
4. Fill out every section in the template.
5. Submit the issue.

If no template appears, copy and paste the template below into your issue body.
